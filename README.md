# فرسان القيم والإحسان — JPIS Life Skills (v10)

Classroom platform for Jeddah Private International Schools.

## Teacher link (share this)

**https://mrhishamfadil.github.io/jpis-life-skills/**

Open in Chrome or Safari on a laptop, tablet, or phone. No login.

Source copy of this build also lives in this repository (`index.html`).

## How to use in class

1. Open the link on the projector or teacher laptop.
2. Choose Arabic or English, boys or girls, and junior mode if needed.
3. Teach the skill cards, scenarios, and exit ticket from the same page.
4. Stars awarded in class are saved to Firestore (`jpis-fursan`) so other classes can see the same school record.

## Notes

- This is the standalone v10 build: styles, icons, illustrations, and audio are inside the page.
- Google Fonts for signature styles need internet on first open.
- Do not put private student names or grades into a public page.
